# Musx A1

- #Beginner's Guide to Building and Installing

Welcome to Musx A1! This guide will help you turn the code into a working Android app using only your phone and GitHub.

## Step 1: Fork the Repository
1. Open this repository on GitHub in your phone's browser.
2. Tap the **Fork** button (usually near the top) to create your own copy of the project.

## Step 2: Enable GitHub Actions
1. In your forked repository, tap the **Actions** tab.
2. If it asks, tap the button that says **"I understand my workflows, go ahead and enable them"**.

## Step 3: Trigger a Build
The app builds automatically whenever you make a change. To trigger it for the first time:
1. Go to the **Code** tab.
2. Open any file (like `README.md`) and tap the **Edit** (pencil) icon.
3. Add a space or a character at the end of the file.
4. Tap **Commit changes...** at the bottom.

## Step 4: Download the App
1. Go back to the **Actions** tab.
2. You will see a workflow running called "Android CI". Wait for it to finish (a green checkmark will appear).
3. Tap on the completed workflow run.
4. Scroll down to the **Artifacts** section.
5. Tap on **app-debug** to download the zip file.

## Step 5: Install on your Phone
1. Locate the downloaded `app-debug.zip` in your phone's file manager and extract it.
2. Inside, you will find `app-debug.apk`.
3. Tap on the `.apk` file to install it.
   - *Note: You may need to allow "Install from unknown sources" in your phone's settings.*

## Step 6: Use the App
1. Open **Musx A1**.
2. Follow the onboarding to select your PDF folder.
3. Your books will appear automatically. Tap a book and press **Play** to start listening!

---
**No PC, No Coding, No Internet needed after installation.** Enjoy your offline knowledge listening experience!
